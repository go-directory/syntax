# subspec

Package subspec implements `SubtreeSpecification` per [RFC3672](https://www.rfc-editor.org/info/rfc3672/).

  - Efficient tokenization and parsing of text-based `subtreeSpecification` values
  - Easy manual type instance assembly
  - Full `Refinement` support
    - Traversable
    - Interface-based
    - Panic-proof indexing
    - Many unit tests, examples
